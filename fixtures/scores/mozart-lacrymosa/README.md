# Lacrymosa (W. A. Mozart, Requiem K. 626), SATB with piano

A public test score for Cantor:

- `mozart-lacrymosa-from-requiem-satb-with-piano.mxl`: MusicXML
  (MuseScore 3.6.2), 4 voices plus piano, 150 measures, Latin lyrics. The
  title and composer are only in `<credit>` text, not in `<work>`, so it
  tests the credit fallback of the header reader.
- `.pdf`: the engraved score, 5 pages.
- `.mscz`: the MuseScore source.
- `.mp3`: a rendered recording, 3 min 5 s, used as a backing-track test
  input.
